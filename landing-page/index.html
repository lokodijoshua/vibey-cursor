Install VibeyCursor

Free forever. Chrome Web Store listing coming soon — until then, install in 30 seconds:

  1. Download the extension (.zip)
  2. Unzip the file anywhere on your computer.
  3. Open chrome://extensions, enable Developer mode (top-right), click Load unpacked, select the unzipped folder.
  4. Pin VibeyCursor to your toolbar. Done — visit any site and flip it ON.
